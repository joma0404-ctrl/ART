# 藝境墨華 · 學生美術得獎作品特展網頁

為資料夾內的 7 幅全國學生美術比賽得獎水墨畫作量身打造的現代化線上數位畫廊與作品展示網頁。

---

## 🚀 快速開啟方式

1. 直接在檔案總管中對 `index.html` 按滑鼠左鍵點擊兩下（或右鍵以 Chrome / Edge / Firefox 等瀏覽器開啟）。
2. 無需安裝任何伺服器或依賴環境，即可流暢瀏覽！

## 🌟 網頁核心特色與互動功能

1. **三種版面瀏覽模式**：
   - 🏛️ **畫廊網格模式**：經典美術館裝裱展牆，兼顧畫面與資訊。
   - 📜 **條幅立軸模式**：依直式水墨條幅比例延伸，聚焦畫面垂直氣勢。
   - 📱 **單幅聚焦模式**：寬幅大圖垂直滾動，如同展開長卷。

2. **多維度篩選與即時搜尋**：
   - 依得獎榮譽快速篩選（全部、特優、優等、甲等、我的收藏）。
   - 即時文字搜尋作者姓名、作品標題、題材標籤或賞析內文。
   - 依得獎名次、筆劃排序。

3. **專業級高解析作品鑑賞器（Lightbox）**：
   - **無級縮放與平移**：滑鼠滾輪縮放、拖曳畫布漫遊、雙擊快速放大。
   - **策展導讀與賞析**：收錄深入的作品背景介紹、評審亮點分析、作品規格與主色墨彩盤。
   - **個人收藏系統**：可將喜愛的作品打星收藏（自動儲存於瀏覽器 LocalStorage）。

4. **全螢幕虛擬導覽（Slideshow Tour）**：
   - 點擊「虛擬導覽」按鈕即可開啟全螢幕沉浸式幻燈導覽，附帶背景動態虛化與進度計時條。

5. **展廳氛圍自訂**：
   - **墨黑展廳 / 宣紙雅白**：自由切換沉浸式夜間聚光燈模式或溫潤宣紙米白模式。
   - **水墨雅音**：內建 Web Audio API 雅音音效（可自由開啟/關閉）。

## ⌨️ 鍵盤快捷鍵指南

- `ESC`：關閉鑑賞視窗 / 退出虛擬導覽
- `←` / `→`：切換上一幅 / 下一幅作品
- `+` / `-`：放大 / 縮小畫面
- `0` 或 `R`：重置畫面縮放比例
- `空白鍵`（導覽模式）：暫停 / 繼續自動播放
